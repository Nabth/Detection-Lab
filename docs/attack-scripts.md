# Red Team: Скрипты эмуляции атак

Для валидации правил детектирования и проверки работы Active Response в репозитории предусмотрен минималистичный набор скриптов для машины атакующего (Kali Linux). Все скрипты лежат в `hosts/kali/attacks/`.

## 🚀 Оркестратор (`run_all.sh`)

Запускает полную симуляцию атак в два этапа:
1. **PHASE 1 (L3/L4)** — запускает `attack_l34.sh`. Использует **подделку IP-адреса (spoofing)**, чтобы проверить детект Suricata и Active Response, не блокируя реальный IP Kali.
2. **PHASE 2 (L7)** — запускает `attack_l7.sh`. Использует **реальный IP** (требуется для TCP-соединения). Скрипт интерактивный: он делает паузы, когда срабатывает защита, и просит оператора разблокировать IP.

## 🛡️ Сетевые атаки (`attack_l34.sh`)

Скрипт эмулирует L3/L4 атаки. Генерирует случайный IP для каждого вектора.
*   **DDoS:** SYN, UDP, ICMP, ACK, RST Flood (через `hping3 --flood`).
*   **Сканирования:** Nmap SYN Scan (реальный IP), XMAS, NULL, Invalid Flags (SYN+FIN, SYN+RST) — со спуфингом.
*   *Примечание:* Атака Slowloris не включена в скрипт, так как Nginx (HTTP/2) отбивает её на уровне TCP, не давая сформировать таймаут. Подробнее в `gap-analysis.md`.

## 💉 Веб-атаки и Brute Force (`attack_l7.sh`)

Скрипт разделен на две фазы:
*   **PHASE 1 (Web/OWASP):** SQLi (5 типов), XSS, Command Injection, LFI, обфускация SQLi, double URL encoding и SQLMap UA. Эти атаки блокируются WAF, но **не вызывают срабатывания Active Response** (IP остается чистым).
*   **PHASE 2 (Banning Attacks):** 
    *   `SSH Brute Force` — вызывает срабатывание Fail2Ban. Скрипт делает паузу и просит оператора выполнить `fail2ban-client unbanip` на Victim.
    *   `HTTP Flood` — вызывает срабатывание Nginx `limit_req` (429), что триггерит Active Response. Скрипт делает паузу и просит оператора очистить `iptables` на Victim.

## ⚠️ Интерактивный режим (Interactive Pause)
Скрипт `attack_l7.sh` использует команду `read -p`. Это сделано намеренно: после блокировки IP его нужно разблокировать для продолжения тестирования. Скрипт выводит точные команды для снятия бана.
